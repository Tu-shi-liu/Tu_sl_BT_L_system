# 基于STM32F103C8T6的蓝牙智能灯光与环境监测系统

#技术栈
>STM32F103C8T6、HAL库、硬件I²C、DMA+IDLE串口接收、非阻塞状态机、定点运算、查表法、PWM驱动。

#项目概述
>集成BMP280、BH1750、HC_05、OLED及RGB_LED，实现温度/气压/光照采集、蓝牙遥控与自动上报、四种灯光模式控制。
